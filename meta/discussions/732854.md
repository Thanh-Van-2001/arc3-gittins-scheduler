    --- CPMP (votes {'totalVotes': 6, 'canUpvote': True, 'totalUpvotes': 6}): > you have to choose two of your seen hidden scores to guess which ones scored the best on the unseen hidden scores that determine the winner. How is that a good idea?

It is THE GOOD IDEA of Kaggle. 

It is set this way to test how well your pipeline generalizes to new, unseen data. 

The purpose of machine learning is to build models that perform well on new data.

If you don't have a hidden test set, then you might build a model or pipeline that works great on the public test data but that would perform badly on new data. Your model would look good when it is useless. This bad outcome is called overfitting in ML. The hidden test set purpose is to check for overfitting.

The real issue is that most benchmark out there have only public test data. People report awesome numbers on these for their LLMs, only for people to be disappointed when they apply these LLMs to new data.

In LLM folklore this is known as benchmaxing, but it is the same as overfitting.
